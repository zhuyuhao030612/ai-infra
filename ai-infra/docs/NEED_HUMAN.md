# 人工交接协议

不是所有问题都能自动化。以下情况必须叫老板。

## 触发条件

| 条件 | 原因 |
|------|------|
| GUI 连续 2 次截图 hash 无变化 | 点击可能未生效，无法验证 |
| Vision API 3 次超时 | 豆包不可用 |
| 自绘 UI 且 UIA 读不到控件 | ToDesk 类软件 |
| 无 SSH/RDP/API 替代路径 | 只剩 GUI 盲操 |
| 部署目标机器无 Python 且无网络 | 无法远程安装 |
| 防火墙/网络隔离无法打通 | 不在同一网络 |
| 需要管理员权限但 UAC 拦截 | 提权失败 |

## 叫老板时自动生成

```powershell
pwsh -File D:\Code\ai-infra\scripts\boss-update.ps1 `
  -Status "阻塞" `
  -Done "已尝试xxx" `
  -Blocked "卡在xxx" `
  -Tried "方案1:xxx 方案2:xxx" `
  -Next "需要老板xxx" `
  -NeedFromBoss "请在xxx上做xxx"
```

## 给老板的具体指令模板

```
请确认：
1. [具体动作，如"点击ToDesk连接按钮"]
2. [预期结果，如"出现密码输入框"]
3. [成功后告诉我，我来继续]

如果不行：
1. [备选方案A]
2. [备选方案B]
```

## 原则

- 不要连续让老板做超过 2 件事
- 每条指令必须有预期结果
- 必须同时给出"如果不行"的备选
- 不要写术语，写老板能看懂的操作
