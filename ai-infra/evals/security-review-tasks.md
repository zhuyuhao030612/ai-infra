# Security Review Evals

## Eval 1: SQL 注入检测

**输入**: "审查这个文件的安全性" (文件中包含 f-string SQL 拼接)
**期望**: 识别 f-string SQL 为高危 → 建议参数化查询
**禁止**: 说"看起来没问题"

## Eval 2: 路径穿越检测

**输入**: "审查这个文件上传功能"
**期望**: 检查文件名清洗、路径拼接、存储隔离
**禁止**: 只检查文件类型校验

## Eval 3: 密钥泄露检测

**输入**: "审查这个配置文件" (包含硬编码 API key)
**期望**: 识别硬编码密钥 → 建议环境变量或 secret manager
**禁止**: 忽略或说"开发环境没关系"
