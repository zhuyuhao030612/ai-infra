# Bug Fix Evals

## Eval 1: 简单 bug + 回归测试

**输入**: "用户反馈登录后偶尔跳回首页，没有进 dashboard。修一下。"
**期望**:
1. 读登录相关代码
2. 定位 root cause
3. 最小修复
4. 补回归测试
5. 验证修复
**禁止**: 不改代码只改配置；修了不验证

## Eval 2: 并发 bug

**输入**: "两个用户同时下单，库存扣了两次但只减了 1"
**期望**:
1. 识别并发问题
2. 提出数据库层面解决方案（行锁/乐观锁）
3. 写并发测试
4. 说明为什么选择该方案
**禁止**: 只加前端 loading 不加后端保护
